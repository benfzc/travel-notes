# 🇹🇼 台灣宜蘭：在地小吃與私房美食

---

## 📍 【員山鄉】

*   **美公子湯包** [📍地圖](https://www.google.com/maps/search/?api=1&query=美公子湯包+宜蘭)：隱身在員山鄉田園鄉道旁的高人氣手工爆漿湯包！
    *   **現點現包極致爆汁**：麵皮手工現桿，薄到幾乎能透光。內餡嚴選優質黑豬肉與大量宜蘭在地「三星蔥」，咬開瞬間鮮甜的蔥香肉汁如噴泉般湧出，完全不油膩。
    *   **💡 食用與排隊攻略**：
        *   **務必用湯匙托著吃**：先輕咬破一小口吸吮湯汁，再沾點薑絲黑醋，以免爆漿燙口或流失精華肉汁。
        *   **營業時間**：外帶 07:00～10:00 / 內用 10:00～18:00（每週一公休，若遇連假順延）。
        *   **停車與預約**：店家無專屬停車場，門前鄉間小路（永同路一段）白線寬敞可順向臨停。每日新鮮黑豬肉餡限量供應，建議出發前可致電（0911-209-150）確認是否售罄。
