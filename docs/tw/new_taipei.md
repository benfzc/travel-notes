# 🇹🇼 台灣新北：在地小吃與私房美食

---

## 📍 【永和區】

*   **君悅豆漿店** [📍地圖](https://www.google.com/maps/search/?api=1&query=君悅豆漿店+新北市永和區福和路257號)
    *   **必點招牌**：燒餅油條（推薦加蔥蛋）、煎蘿蔔糕、小籠包、傳統飯糰、各式小酥餅
    *   **營業時間**：05:30～11:00（週日約 06:00～11:30，無固定公休日，賣完提早收）
    *   **交通與停車**：
        *   距捷運頂溪站或永安市場站步行約 12～15 分鐘
        *   網溪國小地下停車場 [📍地圖](https://www.google.com/maps/search/?api=1&query=網溪國小地下停車場+永和)
        *   永和國小地下停車場 [📍地圖](https://www.google.com/maps/search/?api=1&query=永和國小地下停車場+永和)（步行約 6～8 分鐘）
