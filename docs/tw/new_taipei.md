# 🇹🇼 台灣新北：在地小吃與私房美食

---

## 📍 【永和區】

*   **君悅豆漿店（福和路257號 / 永和在地人私藏早市傳統豆漿老店）** [📍地圖](https://www.google.com/maps/search/?api=1&query=君悅豆漿店+新北市永和區福和路257號)：*不賣宵夜場、只營業早市的永和傳統手工中式早點實力派！* 隱身在永和福和路上，不同於一般 24 小時營業的連鎖永和豆漿，這裡專注於清晨到上午的傳統早市，是在地鄰里與老饕默默排隊的日常口袋名單。
    *   **🔥 必點招牌推薦**：
        *   **燒餅油條（推薦加蔥蛋）**：現烤出爐的燒餅層次分明、外皮酥脆且帶有純粹迷人的老麵麥香；搭配炸得金黃香酥卻毫不油膩的油條，或夾入一份蔥花蛋，咬下滿口酥香。
        *   **古早味煎蘿蔔糕**：店內極受推崇的明星品項！表皮在鐵板上煎得金黃「恰恰」微酥，內裡質地卻有如傳統碗粿般綿密軟嫩，淋上店家特製蒜蓉醬油膏與辣椒醬超對味。
        *   **小籠包、傳統飯糰 ＆ 各式小酥餅**：皮薄多汁的小籠包、糯米Q彈包入酥脆油條與肉鬆的傳統飯糰，以及尺寸精巧酥香的甜／鹹酥餅、蘿蔔絲餅與胡椒餅，搭配濃郁順口的冰熱豆漿或鹹豆漿都非常過癮。
    *   **💡 營業與交通／停車攻略**：
        *   **營業時間**：清晨 **05:30～11:00**（週日約 06:00～11:30，**僅營業早市、熱門酥餅與品項賣完提早收**；無固定公休日，偶爾不定休可先致電 `02-2920-6605` 確認）。
        *   **🚗 交通與停車**：距捷運頂溪站或永安市場站步行約 12～15 分鐘（可轉乘公車至「福和路」或「得和路口」站）。福和路車流量大且紅線拖吊嚴格，切勿違規臨停；開車建議停靠附近的**「網溪國小地下停車場」** [📍地圖](https://www.google.com/maps/search/?api=1&query=網溪國小地下停車場+永和) 或 **「永和國小地下停車場」** [📍地圖](https://www.google.com/maps/search/?api=1&query=永和國小地下停車場+永和)，再步行約 6～8 分鐘前往。
