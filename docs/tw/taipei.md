# 🇹🇼 台灣台北：在地小吃與私房美食

---

## 📍 【萬華區】

*   **豆漿燒餅店（環河南路二段125巷5號 / 華江整宅無招牌老店）** [📍地圖](https://www.google.com/maps/search/?api=1&query=豆漿燒餅店+萬華區環河南路二段125巷5號)：隱身在萬華環河南路二段巷弄騎樓下、傳承三代山東味的無招牌人氣早餐老店（也是台劇《有生之年》取景地）！
    *   **⭐ 實測必點推薦**：**燒餅**與**飯糰**非常好吃！手工現桿現烤的燒餅外酥內軟、帶有迷人麵香；飯糰份量扎實、米飯香Q配料飽滿（推薦加蛋或加一點店家自炒的靈魂辣菜脯／小魚乾辣椒更夠味）。
    *   **💡 營業與停車攻略**：
        *   **營業時間**：清晨 04:30～10:00（假日約至 10:30，賣完提早打烊；每週三固定公休，部分週二不定休）。
        *   **🚗 開車停車建議**：巷弄內較難臨停，開車前往可直接停在正對面過馬路即達的**「台北製糖所文化園區地下停車場」** [📍地圖](https://www.google.com/maps/search/?api=1&query=台北製糖所文化園區地下停車場)，停好車走出來約 1～2 分鐘就到，非常方便！
*   **新鮮豆漿店（中華路二段504巷7號 / 青年公園・國光社區40年老字號）** [📍地圖](https://www.google.com/maps/search/?api=1&query=新鮮豆漿店+台北市萬華區中華路二段504巷7號)：*豆漿濃純、豬排蛋餅表現出色的青年公園巷弄 40 年早餐老店！* 隱身在青年公園斜對面、國光社區老公寓巷弄內，充滿濃厚的古早眷村人情味。
    *   **⭐ 實測必點推薦**：
        *   **現磨豆漿 ＆ 豬排蛋餅**：**豆漿喝起來非常純濃**、黃豆香氣飽滿實在；**豬排蛋餅很好吃**，軟Q的手工蛋餅皮捲入醃製入味、鮮嫩多汁的煎豬排，鹹香夠味超推薦！
        *   **養生紫米飯糰**：店內另一人氣品項，使用黑糯米（紫米）包入自製油條、肉鬆、菜脯與酸菜，口感Q彈有飽足感。
    *   **⚠️ 實吃心得（避雷提醒）**：雖然網路上不少人推薦他們家的燒餅，但**實際吃起來覺得燒餅口感偏乾**（若怕乾口建議直接改點豬排蛋餅，或一定要配豆漿）。
    *   **💡 營業與停車攻略**：
        *   **營業時間**：週日至週三 **05:50～11:00**、週五至週六 **05:30～11:30**（**每週四固定公休**）。
        *   **🚗 開車停車建議**：中華路二段 504 巷內狹窄不易會車，開車建議直接停在斜對面的**「青年公園高爾夫球場地下停車場」** [📍地圖](https://www.google.com/maps/search/?api=1&query=青年公園高爾夫球場地下停車場) 或**「青年公園棒球場地下停車場」** [📍地圖](https://www.google.com/maps/search/?api=1&query=青年公園棒球場地下停車場)，停好車過馬路走進巷內僅約 3～5 分鐘，吃完還可順道在青年公園散步。

## 📍 【大同區】

*   **津津豆漿（延平北路四段5號 / 大橋頭・大龍峒老店）** [📍地圖](https://www.google.com/maps/search/?api=1&query=津津豆漿+台北市大同區延平北路四段5號)：位於延平北路四段與民族西路口附近（04:30～11:00 營業），以手工現桿半煎炸的「韭菜炸蛋餅」聞名。
    *   **📝 實測心得**：實際去吃覺得味道中規中矩，**沒有特別好吃、但也不難吃**（不必特地大老遠專程排隊朝聖）。
    *   **💡 周邊街區探索潛力**：反倒是**附近街上（延平北路四段、大龍峒保安宮及哈密街／酒泉街周邊）白天就非常熱鬧、開了許多在地店家與老字號小吃**，很適合白天順道在附近街區散步探索挖寶！
