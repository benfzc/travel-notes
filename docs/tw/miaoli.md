# 🇹🇼 台灣苗栗：在地小吃與私房美食

---

## 📍 【苑裡鎮】

*   **三月出午（山柑里2-2號）** [📍地圖](https://www.google.com/maps/search/?api=1&query=三月出午+苗栗縣苑裡鎮)
    *   **必點招牌**：手工水餃（蔥肉／玉米，另有冷凍外帶）、辣醬麵／辣醬飯、蛋炒飯、滷味黑白切（推薦沾自製蔥蒜生辣椒、朝天椒辣火山醬）
    *   **營業時間**：11:00～14:00、17:00～19:00（**週一公休**）
    *   **交通與停車**：
        *   距國道 3 號苑裡交流道約 2～3 分鐘車程，門前與隔壁 7-11 鈺田門市周邊寬敞好停車
