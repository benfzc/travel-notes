# 🇹🇼 台灣苗栗：在地小吃與私房美食

---

## 📍 【苑裡鎮】

*   **三月出午（山柑里2-2號 / 國道3號苑裡交流道旁）** [📍地圖](https://www.google.com/maps/search/?api=1&query=三月出午+苗栗縣苑裡鎮)：店名聽起來像文青咖啡廳，實則是苑裡交流道旁（7-11 鈺田門市隔壁）人氣爆棚、高評價的平價家常麵食、水餃與炒飯專賣店！
    *   **🔥 必點招牌推薦**：
        *   **手工現包水餃（蔥肉水餃／玉米水餃）**：皮Q餡飽滿，蔥肉水餃咬開滿滿濃郁蔥香與肉汁，玉米水餃鮮甜討喜，內用吃完還可買冷凍水餃外帶。
        *   **澎湖師承「辣醬麵／辣醬飯」**：老闆特地遠赴澎湖拜師學藝的招牌瘦肉燥辣醬，鹹香微辣又回甘，拌麵或拌飯都非常開胃。
        *   **粒粒分明蛋炒飯**：大火快炒搭配炒飯機翻炒，米飯粒粒分明、鍋氣與蛋香十足（推薦肉絲、香腸或蝦仁蛋炒飯）。
        *   **滷味黑白切 ＆ 兩款靈魂手作辣椒**：滷味入味平價，必沾店家自製的「蔥蒜生辣椒」與「朝天椒辣火山醬」，愛吃辣絕對過癮。
    *   **💡 營業與交通資訊**：
        *   **營業時間**：11:00～14:00、17:00～19:00（每週一公休）。
        *   **🚗 交通與停車**：距離國道3號苑裡交流道僅約 2～3 分鐘車程，門前與隔壁超商周邊寬敞好停車，非常適合作為南北往返下交流道覓食的中繼站。
