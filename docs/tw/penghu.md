# 🇹🇼 台灣澎湖：在地古早味與私房伴手禮

---

## 📍 【湖西鄉】

*   **旭西餅舖（湖西村125號 / 湖西天后宮旁）** [📍地圖](https://www.google.com/maps/search/?api=1&query=旭西餅舖+澎湖縣湖西鄉)：澎湖最具代表性、傳承數十年的手工傳統喜餅老字號，更是澎湖特色古早味點心**「炸棗」**與傳統民俗糕點**「肪片龜（平安龜）」**的指標名店！
    *   **🔥 必買招牌推薦**：
        *   **澎湖傳統手工「炸棗」**：外觀像大號芝麻球，是澎湖人嫁娶、新居落成與廟會必備的吉祥喜餅！以純糯米手工揉製，外皮酥脆、內裡軟Q有嚼勁。最推薦**「花生口味（白芝麻記號）」**（嚴選澎湖在地花生碎搭配少許冬瓜糖，香氣極濃）與**「紅豆／綠豆口味」**，剛起鍋溫熱吃外酥內Q最銷魂。
        *   **古早味手工「肪片龜（鳳片龜／平安龜）」**：澎湖元宵「乞龜」文化最具代表性的靈魂糕點（「龜」音同「歸」，祈求平安歸來與福氣）！以熟糯米粉（鳳片粉）、糖清與畫龍點睛的古早味**「香蕉油」**手工揉合捏製，並在白色龜背上手繪紅綠吉祥龜甲紋與字樣。口感紮實綿密又帶Q彈嚼勁，甜度經過改良清甜不膩，咀嚼時散發迷人的米香與懷舊香蕉油香氣（除了傳統原味白靈龜，第二代創立的體驗品牌「澎福古棗味」亦有推出融入仙人掌汁等在地元素的創意造型與 DIY 體驗）。
        *   **手工米香**：口感酥脆不黏牙、不死甜，有黑糖薑汁、原味等多種在地風味，非常適合買回本島當伴手禮。
    *   **💡 購買與預訂攻略**：
        *   **營業時間**：06:00～17:30（每日清晨開始現作，但散客零售的炸棗與限量糕點常在早市或中午前就會賣完，**強烈建議早上前往**）。
        *   **📞 務必提前電話預留**：由於店家經常接滿在地喜慶與祭祀大單，若想買特定口味的**炸棗**或**指定訂製肪片龜**（尤其是元宵節前後或非節慶期間想購買），強烈建議提前致電（`06-992-1245`）詢問與預留，以免現場撲空！
