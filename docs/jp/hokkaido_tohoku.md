# 北海道與東北地區：札幌、青森

## 🍂 1. 銀杏秘境與殿堂

*   **北海道大學 銀杏並木（札幌）** [📍地圖](https://www.google.com/maps/search/?api=1&query=北海道大學+銀杏並木)：*見頃約 10月下旬～11月上旬*。被譽為日本最美校園之一的銀杏大道。
    *   **北海道大學綜合博物館 (総合博物館)**：位於校園內，免費參觀。館藏極度豐富，包含恐龍化石骨架與各種珍貴標本，建築本身也極具歷史感，是不可錯過的知性景點。
    *   **北大マルシェ Café&Labo (北大 Marche)**：位在校園內的質感咖啡廳。主打使用北大農場自產的鮮奶製作的霜淇淋、布丁與起司，逛完博物館來這裡休息吃甜點非常推薦。
*   **AOAO SAPPORO (都市型水族館)** [📍地圖](https://www.google.com/maps/search/?api=1&query=AOAO+SAPPORO)：位於札幌市中心「moyuk SAPPORO」百貨的 4-6 樓。2023 年全新開幕的都會型水族館！主打近距離觀賞企鵝（企鵝會在你面前跳來跳去），還可以一邊吃著館內「白熊麵包店」的牛角麵包一邊喝啤酒看展，非常適合雨天或晚上前往。
*   **北金澤 大銀杏（青森 深浦町）** [📍地圖](https://www.google.com/maps/search/?api=1&query=北金ヶ沢の大銀杏+青森)：*見頃約 11月中旬～下旬*。日本最大級巨木銀杏，樹齡超過千年，夜間點燈氣勢驚人。
